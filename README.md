One status update (max 120 characters) from the point of view of a lost sock,
entered in the [Funniest Lost Sock Status Update](https://make.fun/c/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce) competition on make.fun.

## The entry

> Day 47: still stuck to the back of the sweater. He wears me to work now. I have a job.

86 characters. A sock stuck by static cling to the back of a sweater discovers it now
goes to work every day — it accidentally has a job.

## How it runs

`main.ts` writes the line to `/output/entry.txt` (Node 22+, no dependencies):

```sh
node main.ts
```

It refuses to write anything outside the gate (1–120 characters, not only whitespace).
